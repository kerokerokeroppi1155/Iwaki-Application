# いわき暮らしマップ

スマートフォンのブラウザで使うことを想定した、いわき移住者向けマップの画面プロトタイプです。検索、カテゴリ絞り込み、スポット選択、現在地への移動に対応しています。

## 開き方

`index.html` をWebサーバー経由で開いてください。現在地ボタンは、ブラウザの位置情報利用許可と HTTPS（または localhost）が必要です。

## 公開前に差し替えるもの

- 地図タイルは動作確認用に OpenStreetMap の標準タイルを参照しています。公開運用では [OpenStreetMap のタイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)を確認し、想定アクセスに合った配信元を選んでください。
- 掲載スポットと説明は仮データです。実データ、投稿者情報、営業時間などを用意して差し替えてください。
